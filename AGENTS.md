# Working on this repository

Read [Development rules](docs/development-rules.md) before working. They govern
development of this project, not the factory's runtime workflow.

Read [the overview](README.md), then use [the design index](docs/README.md) to load
only the contracts relevant to the task. Report conflicting requirements.

[GitHub Issues](https://github.com/thelim3y/agentic-engineering-workflow/issues)
is the backlog. An issue supplies scope and context; it is not authorization to
change unrelated work.
