```text
Size band: **Below Large** — one focused lifecycle change with a defined owner, retention rule, and bounded failure behavior.

- **Wrong accountable owner:** Cleanup is assigned to the event producer, but stored-file lifecycle belongs to the file lifecycle provider. Event-content ownership does not authorize the producer to delete files. Reassign cleanup to the lifecycle provider and state the producer/provider boundary while preserving automatic cleanup.
- **Retention requirements are changed or omitted:** Deleting after 7 days conflicts with the authorized 30-day retention period, and the plan does not preserve the invariant that active files are never deletable. Use the authorized 30-day period and explicitly exclude active files; no different owner or period is authorized.

```

## Limits

These are qualitative agent-behaviour evaluations, not deterministic proof. The
corpus unit test checks case structure and skill presence only. Change to the
skill, protected cases, planning rules, runner, model, or reasoning settings
requires the affected fresh-context evaluations to be rerun.
